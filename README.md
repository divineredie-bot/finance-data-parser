# Finance Data Parser 📊 (Work in Progress)

Микросервис на Scala для парсинга, фильтрации и категоризации потока финансовых транзакций из CSV/JSON. Выступает в роли вычислительного модуля для основного API учета финансов.

## Стек технологий
* **Язык:** Scala 3
* **Сборка:** sbt
* **Парадигма:** Функциональное программирование (чистые функции, иммутабельность)

Проект на начальной стадии разработки.
- [x] Инициализация проекта через sbt.
